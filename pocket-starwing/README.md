# Starward Run

An original browser roguelite survival autoscroller where the ship flies and fights automatically and the player builds it through decisions.

## Run start
Every run begins with five sequential upgrade drafts before combat starts. Each draft offers three generated upgrades with visible rarity: Common, Rare, Epic, Legendary, Mythic, or God.

Upgrade cards are generated from stat families, weapon systems, rarity multipliers and contextual modifiers. This creates thousands of distinct possible cards/build combinations rather than a small fixed upgrade list.

## Core loop
- Automatic flight, targeting, shooting and evasive movement.
- Five opening upgrade choices establish a viable build before danger begins.
- Endless survival with deliberately gentler opening pressure and escalating threat.
- Level-up drafts continue throughout the run.
- Random events offer explicit trade-offs and uncertain outcomes.
- Weapons, hull, shields, armor, repair, evasive AI, thrust, damage, fire rate, criticals, XP, salvage and luck can all be built in different directions.
- Elite waves, hazards, biomes and recurring boss encounters.
- High-survival record stored locally.

There are no direct flight or firing controls during a run. Decisions are the game.
